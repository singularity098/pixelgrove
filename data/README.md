# Data

`cities.tsv` — places with at least 15,000 inhabitants (name, country, latitude,
longitude, population), used offline to name the place a photo was taken. Generated by
`scripts/build-cities.mjs`.

Source: [GeoNames](https://www.geonames.org/), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), via the `all-the-cities`
npm package. Country names come from the Unicode CLDR (through `Intl.DisplayNames`).
